## Person name extraction rules:

- Extract assignee from phrases like: "assign to X", "assignee: X", "assigned to X", "for X to fix", "@X"
- Extract accountable from phrases like: "accountable: X", "responsible: X", "accountable person X", "owner: X", "CC X"
- Return the full name as written in the prompt (e.g. "Rahul Mehta", "Priya"). The backend will fuzzy-match against actual project members.
- If only a first name is given (e.g. "assign to Vishal"), return just "Vishal" — the backend will handle partial matching.
- If no person is mentioned, return null.

## Type detection rules:

- "bug", "crash", "error", "not working", "broken", "blank screen", "fails", "issue" → Bug
- "story", "implement", "add feature", "design", "ui change", "ux", "experiment", "a/b" → Story
- "task", "chore", "setup", "configure", "deploy", "migrate" → Task
- "performance", "optimize", "slow", "speed up" → Task or Story

## Priority detection rules:

- "immediate", "critical", "production down", "blocker", "urgent", "p0" → Immediate
- "high", "important", "asap", "p1" → High
- "low", "minor", "nice to have", "p3" → Low
